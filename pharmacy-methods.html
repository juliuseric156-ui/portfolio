Hospital Pharmacy Analysis

Methods and SQL sample

The dashboard measures fulfillment, flags stock expiry risk, and estimates gross profit from dispensing records.

From records to metrics

  1. Fulfillment. Sum dispensing records per prescription item before matching them to prescriptions. Keep items with no recorded dispense in the denominator. Cap fulfilled units at the prescribed quantity, then divide fulfilled units by prescribed units for each medicine.
  2. Quality checks. Compare recorded statuses with prescribed and dispensed quantities. Flag quantities above the prescription, even though the fulfillment rate caps them. A same-day first dispense can still leave some units outstanding.
  3. Inventory and gross profit. Group remaining stock by expiry window and value it at batch purchase cost. Estimate gross profit by subtracting the purchase cost of dispensed units from recorded charges.
  4. Reorder review. Apply the last 30 days of dispensing pace to batches in expiry order. The pace is an assumption and may change.

Reproduce the dashboard’s fulfillment and stock-value metrics

Run the fulfillment example

The SQL sample uses fictional records to demonstrate the metric independently of the dashboard’s source data. It covers a split fill, an unfilled item, and an over-dispensed item.

Download the SQLite sample

In a terminal with SQLite installed, run this command from the folder containing the downloaded file.

sqlite3 -header -column :memory: < pharmacy-sample.sql

Expected results are 60.0% fulfillment for cetirizine and 66.7% for amoxicillin. Amoxicillin has one flagged over-dispensed item.

Sample data dictionary

  • prescription_items has one row per prescribed item, identified by item_id, with its medicine and prescribed units.
  • dispensing has one row per dispensing event, identified by dispense_id. Multiple events can reference the same item_id.
